# 调度设置与平台内日志

同步管道、数据加工仍分别使用独立的列表、新增和编辑页面。同步表单按基础信息和调度设置分区，只能选择已登记的 ODS UNIQUE 目标；SQL 表单负责加工 SQL 和目标模型。加工依赖、周期、运行与调度启停统一在“工作流”画布维护，目录支持名称/目标表搜索与数据库分页，节点链接到独立编辑页。

## 调度设置

- 同步管道默认每小时整点，可填写自定义六段或七段（含年份）Quartz Cron，最小粒度为分钟（秒字段必须为0）。例如每15分钟 `0 */15 * * * ?`、每3小时 `0 0 */3 * * ?`、每日08:30 `0 30 8 * * ?`、周一09:00 `0 0 9 ? * MON`。SQL 加工仍提供每 5 分钟、每小时整点、每日 02:00 三种策略。
- 已有管道可在尚未注册调度或已暂停且没有运行实例时修改频率；已启用/提交中的调度须先暂停。频率修改保留水位和固定同步边界，重新启用时发布新的工作流和调度，原绑定保留以查询历史实例；不会补跑停用期间的各个计划时刻。
- 预览显示北京时间（Asia/Shanghai）的下三次计划触发时间，只计算计划，不证明调度已上线，也不表示节点会准时启动。排队、上游依赖和资源等待会延后执行。
- 保存配置与启用定时是独立操作。同步管道和 SQL 加工均可停用未来调度；停用不取消已提交实例，不清空运行锁，不回退水位。推荐仅在末端 SQL 加工任务启用定时，使同步和所有声明的上游按依赖顺序执行。
- 表单显示当前引擎实际策略：失败重试最多两次，间隔一分钟，节点超时 50 分钟；独立 SQL 查询超时 45 分钟。它们不是本期新增的可编辑参数。

ODS 是原始数据层，分层名称不要求固定一小时同步。批量 ODS 可以根据时效和数据库压力选择周期；实时 CDC 则是持续消费变更的另一种模式。本次仍为批量时间水位同步。DataWorks 的[周期配置](https://help.aliyun.com/en/dataworks/user-guide/configure-time-properties-1)与[整库离线同步](https://help.aliyun.com/en/dataworks/user-guide/configure-a-database-wide-offline-synchronization-task)同样支持按配置周期生成同步实例。

## 运行实例与节点日志

从同步管道列表的名称或“运行实例”，或工作流列表/画布的“运行实例”进入。选择执行链路版本、状态并分页查询，再进入工作流实例查看节点。失败节点默认优先展开。新发布的加工链路显示该次定义保存的依赖图，状态随现有轮询更新；历史定义缺少图快照时只显示引擎实际节点与日志。

这里直接读取 DolphinScheduler 的真实工作流实例和节点实例。新同步执行会由执行节点携带工作流实例标识领取任务，平台回调记录因此归属到对应工作流实例，并在实例详情展示回调状态、水位范围和结果摘要；回调状态与工作流状态分别显示，工作流成功不等于已收到成功回调。引擎中尚在排队、节点领取失败等情况，可能已经有工作流实例而尚无平台回调记录。实例时间保留引擎返回值；默认 Compose 中 DS 使用 Asia/Shanghai，独立引擎部署应核对其时区。

升级前产生的同步回调未保存工作流实例标识，平台不会按名称或时间猜测关联，保留在同步管道的“历史未关联回调”页面。它们只用于历史排查；新回调应从对应运行实例查看。

实例详情的同步回调直接展示该次实例的全部记录，不提供分页。正常单次执行通常只有一条，失败后重新领取执行时可能产生多条记录；这些重试记录保留展示，并随状态轮询自动更新。工作流实例列表和历史未关联回调列表继续分页。

Flyway V18 为同步记录增加工作流/节点实例编号及组合索引。部署时同时更新平台和 worker 镜像；已发布任务在 DS 默认执行目录下也可携带节点编号，由平台通过 DS 3.4 的 v2 节点详情接口精确反查工作流实例，再核验该工作流属于当前管道，无需重新启用定时。使用自定义执行目录的旧工作流须重新发布，使同步脚本显式接收 DS 内置实例参数。一个工作流实例可能因重试包含多条同步回调，页面保留每次领取与回传结果。未领取、领取前失败和旧执行器产生的实例可能没有可关联回调，不能据此推定同步成功。

- 登录用户可以查看运行状态；仅 ADMIN / DEVELOPER 可以读取节点日志。日志请求不走公开数据 API，不向浏览器提供 DS 令牌。
- 服务端先校验工作流属于当前资源登记的链路，再校验节点属于该工作流，最后读取日志。不接受任意节点编号作为日志授权。
- 工作流与节点状态默认每 5 秒独立更新，包括状态、开始/结束时间、重试次数和新派发节点；不重载整页，保留当前节点、已加载日志及检索条件。工作流和已派发节点均结束后停止自动查询；“刷新状态”可随时重新读取。单个节点失败、工作流尚在重试时不会提前停止。
- “自动追踪日志”默认开启，与状态刷新独立；关闭日志追踪仍会更新执行状态。检测到节点新的重试或替代节点时从头读取对应日志，保留检索条件。状态/日志读取短暂失败时保留已有内容并退避重试，切到后台时暂停新增请求，返回页面后继续。
- 每次默认读取 200 行，最多 1000 行，支持继续加载、从头读取、跟随底部和已加载内容检索。页面最多保留最近 10000 行，下载内容仅为当前已加载窗口，经过相同脱敏，不提供原始日志下载代理。
- 首屏的 DS 文件路径/主机头不展示，也不计入后续行偏移；日志按纯文本展示，配置敏感行和连接地址会隐藏。日志读取记录操作审计，响应禁止缓存。
- 节点未派发、日志被引擎清理、令牌失效或引擎离线时显示暂不可用，并保留平台记录入口；不能把平台简要消息当作完整引擎日志。不会改变任务状态或自动释放互斥。

## 历史与升级

新增 Flyway V9 登记资源与 DS 工作流定义的绑定；升级自动登记现存同步/SQL 任务的当前定义。后续发布或复用 SQL 链时会登记该链的全部同步和 SQL 节点，源任务也能查看自己参与的链。链路更新后保留旧绑定。

升级前已被替换且未登记的旧定义，不会按名称或平台运行编号猜测归属，仍需从 DS 控制台查询。引擎删除的实例和日志无法由此模块恢复；平台不另存日志全文。

## 验证

`mvnw verify` 覆盖 DS API 契约、日志行偏移、预览时区、权限拒绝、实例/节点归属、脱敏、分页筛选、页面渲染、故障降级和调度停用语义。运行完整环境后可执行：

```powershell
python deploy/scheduling_smoke.py
```

冒烟只读验证现有已执行任务的实例与日志，不新建任务、不触发运行、不启用调度。没有可读真实实例时会明确失败，不将空页面当成日志验收成功。

2026-10-24 验证：全量 Maven verify 113 项通过，随后新增的历史链路绑定专项 1 项通过，节点展示排序调整后平台集成回归 17 项通过。真实 DS 3.4.0 环境读取同步与 SQL 两类节点日志并验证首段/续段偏移；历史日志已不可用的实例返回明确降级提示。浏览器验证周期切换、三次预览、上游筛选、日志加载/重置/检索、浅深主题和 390px 移动布局，无脚本错误。未触发新的业务任务或启用定时。

状态自动更新改造的相关 Java 测试 25 项通过，包含结束状态、失败重试、晚到节点、VIEWER 状态读取及跨资源拒绝。真实 DS 已完成实例的状态接口读取通过；浏览器使用受控状态响应验证运行中到成功、关闭日志追踪仍更新状态、结束后停止轮询、手动刷新不重载、故障恢复、等待节点到派发及重试后日志重读。浏览器保留已有检索条件及日志，无脚本错误；本轮未触发新的业务执行。

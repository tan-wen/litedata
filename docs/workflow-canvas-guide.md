# 加工任务画布使用说明

适用版本：LiteData 0.1.0-SNAPSHOT。界面与执行规则更新于 2026-11-06。

## 1. 先了解加工任务如何执行

加工任务是独立的调度单元：保存自己的 SQL 节点、依赖连线、触发模式和启停状态。SQL 任务只保存名称、目标模型、SQL 和版本，没有独立执行周期或调度状态。

- 先创建加工任务，再在空白画布中设计任务。无需预先指定末端任务。
- 支持多个起点、分支、汇合和多个输出，也允许暂时不连线的节点。
- 手动运行或 Cron 触发时，执行本加工任务保存的所有节点；没有上游的节点可先执行，其余节点等待本次运行的所有直接上游成功。
- 每次运行重新执行当前流程的全部 SQL，不复用其他运行的 SQL 结果。同步与加工之间通过可选质量门禁及数据就绪事件衔接。
- 不相连的分支也属于本加工任务，运行时会一起执行。节点放在相邻位置不代表存在依赖。
- 连线和 SQL 任务都属于当前加工任务。SQL 不能加入其他加工任务，也不提供子流程或公共加工逻辑复用。

例如：

```text
订单明细 → 客户汇总
                  ↘ 园区汇总
```

客户汇总和园区汇总都可作为输出，无需选出唯一末端任务。

### 同步与加工的触发边界

同步任务不加入画布。加工任务在新建或编辑信息页选择 Cron 或单来源事件模式；配置与放行条件见[数据就绪事件](data-ready-triggers.md)。

## 2. 准备与权限

- ADMIN、DEVELOPER 可以创建、编辑、运行和调度；VIEWER 只读。节点日志权限沿用平台的受限日志规则。
- SQL 目标必须是已登记的 DIM、DWD、DWS 或 ADS UNIQUE 模型。可以先保存逻辑模型与 SQL，执行前须完成 Doris 建表并通过结构核验。
- 同步任务负责 ODS 贴源同步。需要时先配置数据源与 ODS 目标，从同步任务独立页面维护。
- SQL 只允许单条 warehouse `INSERT INTO ... SELECT`；一个目标模型对应一个加工任务。

## 3. 创建加工任务

1. 从左侧“数据加工”进入任务列表，点击“新建加工任务”。
2. 在“基本信息”步骤填写任务名称及说明，点击“下一步：触发与调度”。
3. 在“触发与调度”步骤选择触发方式：Cron 定时在同一步填写表达式并预览下三次北京时间；数据就绪事件选择一个同步任务作为放行来源。
4. 点击“创建任务并打开画布”，触发设置随任务保存；在空白画布中新增 SQL 并编排依赖，保存后返回“数据加工”列表启用定时或事件订阅。需要修改触发设置时通过“编辑信息”返回分步表单。

空加工任务可保存为草稿，添加至少一个节点后才能运行或启用定时。名称和说明可通过“编辑信息”修改。

## 4. 认识画布页面

| 区域 | 用途 |
| --- | --- |
| 顶部信息区 | 加工任务名称、说明、运行加工任务、编辑信息、运行记录和返回数据加工入口；事件模式显示事件记录 |
| 画布 | 查看节点、连线、移动位置、编辑 SQL |
| 工具栏 | 自动布局、缩放、适应画布、删除选中、新增SQL加工节点、保存画布 |

画布内部可滚动。

## 5. 添加任务并建立依赖

### 5.1 准备来源数据

在同步任务独立页面配置 ODS 接入与可选质量任务；需要自动衔接时，在加工任务的信息页订阅一个来源的数据就绪事件。画布不显示同步节点。

### 5.2 在画布中创建 SQL

1. 直接新增 SQL；打开 SQL 编辑器不会自动保存任何画布改动。
2. 点击“新增SQL加工节点”。
3. 在“新增SQL加工节点”弹窗填写节点名称，先选择目标模型，编辑器自动填入 `INSERT INTO warehouse.目标表 (字段列表)` 片段，字段按模型中登记的顺序排列并加反引号，再补全 `SELECT` 查询。SQL 可自由修改，保存画布时写入表必须与所选模型一致。
4. 点击“确认修改（待保存画布）”后，任务加入本地画布草稿；点击页面“保存画布”才会提交。
5. 为它连接所需上游，再保存画布。

“确认修改（待保存画布）”只做必填检查并保留本地草稿；节点、连线、模型、SQL 和版本的最终统一校验在“保存画布”时执行。最终校验失败会保留全部草稿，并通过页面右侧通知说明原因。已被有效 SQL 任务或当前画布草稿占用的目标模型不可选择；删除当前画布中的 SQL 节点或把它改为其他模型后，该模型会立即可选。

同步任务使用独立配置页，通过事件订阅与加工衔接。

### 5.3 使用端口连线

先点击上游节点右侧端口，再点击下游 SQL 节点左侧端口。也可按 Tab 聚焦端口后按 Enter 或空格激活：先激活输出端口，再激活输入端口。当前采用依次点击的操作方式，拖动节点仅用于移动位置。

### 5.4 检查依赖

- 每个加工任务最多 100 个节点；空图可作为草稿。
- 画布只允许 SQL 节点；同步不能作为画布上游或下游。
- SQL 节点可以既接收上游，也作为其他 SQL 的上游。
- 不允许自身依赖、循环依赖、重复连线或指向画布外节点。
- 孤立节点及独立分支会参与运行；不需要执行的节点应移出画布。

## 6. 移动、移出和编辑节点

### 6.1 调整布局

拖动节点或点击“自动布局”，再保存画布。仅保存布局不会改变 SQL 版本，也不会使已发布定义失效。缩放只影响查看比例。

### 6.2 删除连线或移出节点

选中节点或连线，点击“删除选中”，核对后保存。移出节点会删除与它相连的边，其他节点保持在画布上。保存后，移出的 SQL 节点会归档其私有 SQL 定义并释放名称和目标模型；物理数据和运行历史保留。

删除依赖不会改写 SQL；请检查其读取的数据是否仍由其他方式及时刷新。

### 6.3 编辑任务

SQL 节点点击“编辑 SQL”，可直接在画布内修改名称、目标模型和 SQL，输入框提供随主题切换的 SQL 语法高亮；确认修改只更新本地草稿，保存画布时才会同时更新任务和当前加工任务版本。SQL 不在独立入口复用或编辑。

打开编辑器保留已有 SQL。切换目标模型时，替换可识别的开头 `INSERT INTO` 写入表名；与自动生成格式一致的字段列表随模型更新，没有字段列表时自动补入，自定义字段子集、顺序和格式保留。CTE 和查询内容保持原文；不能可靠识别时保留全文并提示手动调整。清空模型选择不会清空 SQL，重新选择后可继续编辑。

SQL 修改只影响当前加工任务；修改前须暂停该流程的定时调度，并等待任务结束。

## 7. 保存画布与处理私有 SQL

“保存画布”事务内校验节点、连线、模型摘要、任务版本、布局和 Cron；任一校验失败都不局部保存。

节点、连线、位置和 SQL 定义共用一份本地画布草稿，需点击“保存画布”一次提交。画布保留任务已有的触发配置，不展示或编辑 Cron。SQL 弹窗的“确认修改”不会发起保存请求；节点会标记“SQL 草稿待保存”。通过页面链接或表单离开时，使用随主题切换的确认框，可选择“继续编辑”或“放弃修改并离开”；保存后不再提示。刷新、关闭标签页或使用浏览器前进/后退离开时，仍由浏览器原生确认保护未保存修改。

运行和启用定时前须保存草稿。新增或编辑 SQL 不会自动保存。保存失败时保留全部草稿。列表中的启停操作只使用已保存的配置，不会提交未保存的画布草稿。

并发修改后可能提示“加工任务或任务配置已变化”；重新加载并核对他人的修改后再操作。

修改节点、依赖、Cron 或私有 SQL 前须暂停当前加工任务；仅修改布局不要求暂停。

## 8. 运行与定时调度

### 8.1 手动运行

Cron 模式保存后点击画布顶部“运行加工任务”，会提交当前加工任务的全部 SQL 节点。事件模式从来源同步任务运行，质量放行后由事件启动加工；不提供手动绕过门禁。提交成功表示引擎接受请求；实际成功以运行记录和节点回调为准。下游等待本次运行的直接上游成功；失败或未执行的上游不会因过去成功而被跳过。

### 8.2 设置执行周期

在新建或编辑加工任务的“触发与调度”步骤填写 6 或 7 段 Quartz Cron：`秒 分 时 日 月 周 [年]`。秒必须为 `0`，日与周恰有一个为 `?`，且存在未来触发时间。时区固定为 Asia/Shanghai（北京时间）。

| 示例 | Cron |
| --- | --- |
| 每 15 分钟 | `0 */15 * * * ?` |
| 每 3 小时 | `0 0 */3 * * ?` |
| 每日 08:30 | `0 30 8 * * ?` |
| 工作日 09:00 | `0 0 9 ? * MON-FRI` |
| 每月最后一天 02:00 | `0 0 2 L * ?` |

示例仅说明语法；界面直接填写表达式，不提供特例周期选择。预览最多显示 3 次未来计划；限定年份等场景可能仅剩 1–2 次。预览不代表调度已启用。

先保存 Cron 和画布，再返回“数据加工”列表点击该任务的“启用定时”；事件模式使用“启用事件订阅”。若调度处于“待上线”，可点击“重试启用定时”继续上线已有调度。修改已启用的周期时，先在列表暂停，再编辑并保存周期，最后回到列表重新启用。启停完成后保留列表的搜索条件和分页位置，不会补跑暂停期间的计划。

### 8.3 暂停

在“数据加工”列表点击“暂停定时”或“暂停事件订阅”，停止未来触发，已提交的任务继续执行，不清空运行锁或回退同步水位。模型或配置异常时仍可暂停。

## 9. 查看运行图与节点日志

从加工任务列表或画布进入“运行记录”。选择运行记录后查看各节点状态，点击节点进入受限分页日志。

运行图来自发布时保存的不可变拓扑快照；之后修改画布不会改变历史图。没有快照的旧定义不根据当前配置补画，仍可查询其已绑定运行记录及日志。

“数据加工”详情展示该 SQL 节点最近 100 条平台执行记录和唯一所属加工任务；同步运行记录及水位在“数据同步”查看。SQL 上游未成功、节点未领取执行权时，不会产生对应 SQL 执行记录。

## 10. 删除加工任务

列表的“删除”移除流程配置入口，并归档该流程私有 SQL 定义；同步任务、物理数据、SQL 运行记录和引擎历史快照保留，SQL 名称和目标模型会释放。启用或提交中的定时须先暂停，节点仍在运行时不能删除。删除前会确认流程名称；并发修改或执行中的错误会在列表提示。

删除后的流程不能再从画布运行。已保存的调度历史仍可通过原运行记录地址查看。

## 11. 常见问题和边界

- 开发测试按新模式重新建立配置，不迁移旧混合依赖图。
- 同步成功水位不因质量或 SQL 加工失败回退。
- SQL 任务与同步任务各自有运行互斥。
- 本期没有单节点运行、从失败节点续跑、跨加工任务周期实例依赖、子流程、公共加工逻辑复用或业务日期补数参数。
- UNIQUE KEY 幂等覆盖不能自动清除源端删除、维度变更后遗留的聚合结果；重算策略见[数据加工](sql-transforms.md)。
- 运行失败、结果未知及运行锁恢复参见[数据加工](sql-transforms.md#中断恢复)；调度和日志权限参见[调度运维](scheduling-operations.md)。

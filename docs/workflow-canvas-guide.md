# 工作流画布使用说明

适用版本：LiteData 0.1.0-SNAPSHOT。界面与执行规则更新于 2026-11-02。

## 1. 先了解工作流如何执行

工作流是独立的调度单元：保存自己的节点、依赖连线、Cron 和启停状态。SQL 任务只保存名称、目标模型、SQL 和版本，没有独立执行周期或调度状态。

- 先创建工作流，再在空白画布中设计任务。无需预先指定末端任务。
- 支持多个起点、分支、汇合和多个输出，也允许暂时不连线的节点。
- 手动运行或 Cron 触发时，执行本工作流保存的所有节点；没有上游的节点可先执行，其余节点等待本次实例的所有直接上游成功。
- 每次运行都会重新执行同步节点和上游 SQL，不复用其他实例的成功记录。独立运行上游不会自动触发下游。
- 不相连的分支也属于本工作流，运行时会一起执行。节点放在相邻位置不代表存在依赖。
- 连线只属于当前工作流。复用同一个 SQL 任务时，各工作流可以使用不同连线；SQL 定义本身仍是共享的。

例如：

```text
同步订单 → 订单明细 → 客户汇总
                  ↘ 园区汇总
```

客户汇总和园区汇总都可作为输出，无需选出唯一末端任务。

### 同步管道的独立周期

同步管道仍可独立定时。加入工作流不会自动暂停它，也不会让工作流使用管道的 Cron。

如果同时启用了两者，管道会分别被独立调度和工作流触发。画布对已启用独立调度的同步节点显示提示。由工作流统一负责同步时，应在同步管道页面暂停独立调度，仅启用工作流；如确需不同频率的独立同步，可以保留两套调度并评估重复运行和资源占用。

同一管道仍受运行互斥保护；冲突可能等待重试或失败，互斥不会把两套计划自动合并成一次。

## 2. 准备与权限

- ADMIN、DEVELOPER 可以创建、编辑、运行和调度；VIEWER 只读。节点日志权限沿用平台的受限日志规则。
- SQL 目标必须是已登记的 DIM、DWD、DWS 或 ADS UNIQUE 模型。可以先保存逻辑模型与 SQL，执行前须完成 Doris 建表并通过结构核验。
- 同步管道负责 ODS 贴源同步。需要时先配置数据源与 ODS 目标，或从画布入口进入同步管道新增页。
- SQL 只允许单条 warehouse `INSERT INTO ... SELECT`；一个目标模型对应一个加工任务。

## 3. 创建工作流

1. 打开“工作流”，点击“新建工作流”。
2. 填写名称及说明，点击“创建并打开画布”。
3. 在空白画布中新增 SQL，或从目录添加已有任务和同步管道。

空工作流可保存为草稿，添加至少一个节点后才能运行或启用定时。名称和说明可通过“编辑信息”修改。

## 4. 认识画布页面

| 区域 | 用途 |
| --- | --- |
| 顶部信息区 | 工作流名称、说明、Cron、状态、编辑信息和运行实例入口 |
| 集中运行与调度 | 手动运行、Cron、启用定时或暂停 |
| 添加任务 | 新增 SQL、创建同步管道、搜索和分页选择已有任务、下拉框连线 |
| 画布 | 查看节点、连线、移动位置、编辑 SQL 或同步管道 |
| 工具栏 | 自动布局、缩放、适应画布、删除选中 |
| 底部 | 保存画布及返回列表 |

窄屏下任务目录排列在画布下方；画布内部可滚动。

## 5. 添加任务并建立依赖

### 5.1 从目录添加已有任务

搜索名称或目标表，点击目录项，将该任务作为单个节点加入。添加不会自动复制其他工作流的上游或连线，也不会自动连接到当前选中节点。同一任务在同一画布只出现一次。

### 5.2 在画布中创建 SQL

1. 保存当前画布中的连线、位置和 Cron 草稿。
2. 点击“新增 SQL 加工”。
3. 填写任务名称、目标模型和 SQL。
4. 保存后，任务自动加入当前画布。
5. 为它连接所需上游，再保存画布。

校验失败时保留编辑内容并在编辑面板显示原因。已有目标模型被任务占用时，应从目录添加已有任务。

新增同步管道仍使用独立配置页；返回画布后，从目录搜索并加入。

### 5.3 使用端口连线

先点击上游节点右侧端口，再点击下游 SQL 节点左侧端口。当前采用依次点击的操作方式，拖动节点用于移动位置。

### 5.4 使用下拉框连线

在左侧选择“上游节点”和“下游加工任务”，点击“添加连线”。

### 5.5 检查依赖

- 每个工作流最多 100 个节点；空图可作为草稿。
- 同步管道只能作为上游，不能接收其他节点的连线。
- SQL 节点可以既接收上游，也作为其他 SQL 的上游。
- 不允许自身依赖、循环依赖、重复连线或指向画布外节点。
- 孤立节点及独立分支会参与运行；不需要执行的节点应移出画布。

## 6. 移动、移出和编辑节点

### 6.1 调整布局

拖动节点或点击“自动布局”，再保存画布。仅保存布局不会改变 SQL 版本，也不会使已发布定义失效。缩放只影响查看比例。

### 6.2 删除连线或移出节点

选中节点或连线，点击“删除选中”，核对后保存。移出节点会删除与它相连的边，其他节点保持在画布上。任务本身、目标表和历史记录保留。

删除依赖不会改写 SQL；请检查其读取的数据是否仍由其他方式及时刷新。

### 6.3 编辑任务

SQL 节点点击“编辑 SQL”，可直接在画布内修改名称、目标模型和 SQL；保存会同时更新任务和当前工作流版本。独立的“数据加工”编辑页仍保留。

共享任务的 SQL 修改会影响所有引用它的工作流，所以修改前须暂停这些工作流的定时调度，并等待任务结束。画布连线的修改只影响当前工作流。

同步节点点击“编辑同步管道”进入独立页。切换前先保存画布草稿。

## 7. 保存画布与处理共享任务

“保存画布”事务内校验节点、连线、模型摘要、任务版本、布局和 Cron；任一校验失败都不局部保存。

节点、连线、位置和 Cron 的普通画布改动需点击保存。刷新会丢失未保存草稿。在画布内保存 SQL 则会立即保存任务，并自动将新任务加入当前工作流。

有未保存草稿时，请先保存再运行、启用定时、编辑 SQL 或离开画布。暂停未来调度不受草稿阻挡。

并发修改后可能提示“工作流或任务配置已变化”；重新加载并核对他人的修改后再操作。

修改节点、依赖和 Cron 前须暂停当前工作流；仅修改布局不要求暂停。修改共享 SQL 前须暂停所有引用它的工作流。删除当前工作流中的一个引用不会删除其他工作流中的引用。

## 8. 运行与定时调度

### 8.1 手动运行

保存后点击“运行”，会提交当前工作流的全部节点。提交成功表示引擎接受请求；实际成功以运行实例和节点回调为准。下游等待本次实例的直接上游成功；失败或未执行的上游不会因过去成功而被跳过。

### 8.2 设置执行周期

填写 6 或 7 段 Quartz Cron：`秒 分 时 日 月 周 [年]`。秒必须为 `0`，日与周恰有一个为 `?`，且存在未来触发时间。时区固定为 Asia/Shanghai（北京时间）。

| 示例 | Cron |
| --- | --- |
| 每 15 分钟 | `0 */15 * * * ?` |
| 每 3 小时 | `0 0 */3 * * ?` |
| 每日 08:30 | `0 30 8 * * ?` |
| 工作日 09:00 | `0 0 9 ? * MON-FRI` |
| 每月最后一天 02:00 | `0 0 2 L * ?` |

示例仅说明语法；界面直接填写表达式，不提供特例周期选择。预览最多显示 3 次未来计划；限定年份等场景可能仅剩 1–2 次。预览不代表调度已启用。

先保存 Cron，再点击“启用定时”。修改已启用的周期时，先暂停、修改并保存，再重新启用。不会补跑暂停期间的计划。

### 8.3 暂停

点击“暂停”只停止未来定时触发，已提交实例继续执行，不清空运行锁或回退同步水位。模型或配置异常时仍可暂停。

## 9. 查看运行图与节点日志

从工作流列表或画布进入“运行实例”。选择实例后查看各节点状态，点击节点进入受限分页日志。

运行图来自发布时保存的不可变拓扑快照；之后修改画布不会改变历史图。没有快照的旧定义不根据当前配置补画，仍可查询其已绑定实例及日志。

“数据加工”详情展示该 SQL 节点最近 100 条平台执行记录和引用它的工作流；同步实例及水位在“同步管道”查看。SQL 上游未成功、节点未领取执行权时，不会产生对应 SQL 执行记录。

## 10. 常见问题和边界

- 旧版工作流升级后会保留节点、连线、Cron、调度编号、启停状态和历史记录，无需重新创建。SQL 任务的调度字段已迁入工作流。
- 工作流内的同步节点按管道自身成功水位增量读取。DataX 成功推进的水位不因下游 SQL 失败而回退。
- SQL 任务与同步管道各自有运行互斥；共享任务被多条工作流重复触发时仍可能产生排队或重试。
- 本期没有单节点运行、从失败节点续跑、跨工作流周期实例依赖或业务日期补数参数。
- UNIQUE KEY 幂等覆盖不能自动清除源端删除、维度变更后遗留的聚合结果；重算策略见[数据加工](sql-transforms.md)。
- 运行失败、结果未知及运行锁恢复参见[数据加工](sql-transforms.md#中断恢复)；调度和日志权限参见[调度运维](scheduling-operations.md)。

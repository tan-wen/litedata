# 数据字典与主题域

管理员从“系统管理 → 数据字典”（`/dictionaries`）维护标准选项。字典列表、字典项列表均使用数据库分页，新增和编辑使用独立页面，保存、取消及校验失败保留分页和检索上下文。

## 按行业维护标准项

系统内置“主题域”（`SUBJECT_AREA`）字典，管理员可以根据行业新增生产制造、客户经营、设备运维等主题域，自行设置编码、名称、说明、排序和启用状态。不预设固定的行业主题域集合；升级时自动收集模型、指标、资产目录和数据服务中已经使用的主题域，保留原值作为编码，避免已有绑定丢失。

字典项编码用于绑定，创建后固定；界面显示字典项名称，名称可以调整，改名后引用该编码的资产和表单显示同步更新。排序数字越小越靠前，同排序按创建顺序排列。自动生成 ODS 模型使用默认的“贴源接入”项，其显示名称也可以调整。

停用项不再用于新绑定；原绑定仍显示，并可在编辑时保留。已有资源引用的主题域不能直接删除，可先停用，或调整全部绑定后删除。系统主题域字典本身不能删除。管理员也可以新建其他字典类型及字典项，作为后续标准选项的配置入口；业务字段需要明确接入对应字典后才会使用它，不会自动替换平台的固定运行规则。

## 业务表单与数据服务

模型、指标、资产目录信息和数据服务的主题域统一通过下拉框选择，服务端校验编码存在且可以绑定。模型与指标的主题域必填；服务可以暂不选择，在资产目录归入“未分类”。检索下拉框保留停用项，以便查询历史资产。

数据服务新增、编辑页还提供“接口用途说明”，最多 2000 字符，用于说明业务用途、适用场景、数据范围和使用注意事项。服务列表、调用记录页和资产详情展示这些信息。主题域与用途说明由数据服务和资产目录共用一份数据；在任一入口修改后即时同步。

仅修改服务名称、主题域或用途说明时保留发布状态和已有访问凭证。修改查询 SQL 后恢复为草稿，需要重新确认并发布。主题域分类不授予数据访问权限，访问凭证与现有权限规则继续生效。

升级迁移 `V26__standard_dictionaries_and_service_metadata.sql` 新增字典及服务元数据，将原服务目录中的主题域、说明迁移到服务定义，保留目录的其他业务标签和版本信息。未登记、停用项的新绑定、编码篡改及过期编辑会被拒绝。

演示与冒烟脚本使用管理员会话，通过正常表单首次登记自身需要的主题域；已有字典项直接复用，不覆盖其显示名称，不重新启用停用项。化工园区示例的模型、指标及服务统一绑定 `chemical_park`，显示名称可在字典中调整。

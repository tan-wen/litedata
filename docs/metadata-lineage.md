# 元数据与表级血缘

入口为“数据治理 → 元数据与血缘”（`/metadata`）。ADMIN、DEVELOPER 可采集，VIEWER 可浏览目录、字段结构和血缘。

## 使用

1. 打开“采集元数据”独立页面，选择 Doris 数仓或已登记的 MySQL、PostgreSQL、SQL Server、Oracle 数据源。
2. Doris 固定采集 `warehouse`；MySQL 采集 JDBC URL 指定的数据库，读取 `information_schema.TABLES/COLUMNS`。其他源通过 JDBC 结构接口读取对应模式（PostgreSQL 的 currentSchema、SQL Server 的 dbo、Oracle 的用户模式），不扫描业务数据。连接范围见[数据源说明](data-sources.md)。
3. 在目录按库表名、注释、数据源、模型名称和分层检索，使用数据库分页。只有 Doris 表关联平台逻辑模型。
4. 打开表详情查看字段、类型、可空、主键标记、注释和上次发现时间。MySQL 主键标记取 `COLUMN_KEY='PRI'`，其他源取 JDBC 主键元数据；不支持该属性的引擎显示“—”，不能替代 Doris 模型的 UNIQUE KEY 核对。
5. 点击“查看血缘”，选择上游、下游或上下游及 1–6 层；图支持缩放、拖动、节点跳转，关系明细链接到产生关系的任务。未采集或最近未发现的节点使用虚线边框。

## 快照与身份

Flyway `V5__metadata_catalog.sql` 新增采集范围、表和字段快照，不修改业务库。按范围加锁，完整读取成功后在同一事务中替换字段；采集或保存失败回滚，不覆盖旧快照。表数最多 2000，每表最多 500 字段，每条结构查询超时 15 秒；超限、非法标识符或空字段结构明确失败。

同一表按“数据源 ID / 数据库 / 表名”定位，Doris 使用独立的 `doris / warehouse / 表名` 身份，避免不同数据源的同名表混为一体。MySQL 标识符保留大小写；Doris SQL 名称沿用当前加工策略的小写规范。采集器要求库、表、字段名符合平台现有字母、数字、下划线且不超过64字符的约定。

重复采集相同结构不增加版本；表注释或字段结构变化使版本递增。当前仅保留最新结构及版本号，未提供历史结构回放。成功采集未再发现的表保留旧结构并标记，不删除元数据；恢复发现后取消标记。该标记也可能由账号可见范围变化造成，不能单独证明物理表已删除。变更物理结构后需要再次手动采集，尚未启用定时采集。

## 血缘依据和边界

- 同步管道：源库表 → Doris ODS 目标表；旧管道 SQL 待迁移时仅提示，不作为有效加工关系展开。迁移后的 SQL 关系来自独立数据加工任务。
- 独立 SQL 加工：通过已有 JSqlParser 解析单条 `INSERT INTO ... SELECT` 的真实表读写关系，支持可解析的 JOIN、子查询、UNION、CTE。CTE 别名不会作为物理表；跨库、无来源表或无法解析的语句产生提示，其 SQL 关系不展示。
- 血缘依据当前任务定义实时生成，包含草稿与未发布任务，归档 SQL 任务被排除；它不代表运行成功，不使用调度先后关系推断数据依赖，不读取执行历史推断实际流量。
- 本页未解析库内视图定义、外部脚本、平台外任务、字段级映射或数据服务消费关系。指标的字段级追溯通过[指标字段血缘](metrics.md#指标字段血缘)提供，采用更保守的 SQL 支持范围及版本快照，不改变本页的表级解析范围。表级环路会保留并使用有界遍历，不能以图形显示结果替代任务合法性校验。
- 图默认上下游各3层，支持最多6层；最多120个节点、300条关系，达到上限会明确提示截断。平台最多支持5000条同步管道和5000条未归档 SQL 任务的血缘索引，超过时明确拒绝生成图，避免静默遗漏。

## 验证

`MetadataIntegrationTest` 使用真实 Testcontainers MySQL 验证 V5、版本、回滚、同名表隔离、分页、权限、页面和血缘；采集边界 mock。`JdbcMetadataCollectorTest` 验证 JDBC 参数绑定、范围、资源释放和上限；`LineageSqlTest` 验证 CTE/JOIN/UNION 与不支持语句。真实 Doris/MySQL 结构采集与浏览器交互需要在实际环境另行验证，不等同于 DataX / DolphinScheduler 全链路验收。

历史实测覆盖 Doris/MySQL 结构采集、字段详情、表级图的缩放/拖动和方向/层数、任务跳转及主题/移动布局。该范围不含同步、加工或容量验收，每次发布仍需在实际环境重新验证。
